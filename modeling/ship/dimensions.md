# 宇宙船と宇宙服の寸法取り（#34 第0段）

NASA の 3D モデル（下敷き）を Blender 5.1.2 のコマンドラインで測った結果。第1段（宇宙船の外観 `Ship_Stack`）で使う寸法の案を最後に書く。

- 測るスクリプト：`modeling/ship/measure.py`（読むだけ。midori のファイルは上書きしない）
- 実行：`/Applications/Blender.app/Contents/MacOS/Blender -b --factory-startup --python modeling/ship/measure.py`
- 生の値：`modeling/ship/measure_out.json`（輪郭の表も入っている）
- 「公表値」はすべて Fable 5.2 の記憶から書いた。出典の文書と突き合わせていない。確かさを「高・中・推測」で付けた

## 0. 結論

1. **3つとも、モデルの単位は実物の m ではない。** Blender では「1 unit = 1m」として読み込まれるが、実物と比べると司令船・機械船は太さが約 1.31 倍、月着陸船は胴がほぼ等倍で脚だけ約 0.68 倍、宇宙服は高さ 74（インチと思われる。推測）。
2. **倍率が部位ごとに違う**（下の表の「モデル÷実物」が 0.66〜1.39 にばらつく）。一律に拡大・縮小しても実寸にならない。
3. だから第1段は、**大きさは実物の公表値、形と部品の位置（何がどこに付いているか）は NASA モデル**から取る。計画（A 章 5番）の「NASA メッシュで寸法だけ取り」は、このとおり「比率と配置だけ取る」に読み替える。

## 3. 宇宙服（`modeling/source/nasa/Astronaut.glb`）

メッシュ1つ。Z が上、+Y が背中。腕を前に曲げ、足を少し開いた立ち姿。単位は不明（高さ 74.263。インチなら 1.886m。推測）。アポロの宇宙服ではなく、背中の装置が大きい型（スペースシャトル期の船外活動服に見える。見た目からの推測）。**比率だけ使う。**

| 測った所 | モデルの値 | 身長に対する比 |
|---|---|---|
| 身長（足の底〜ヘルメットの上） | 74.263 | 1.000 |
| 背中の装置の高さ | 43.340 | 0.584 |
| 背中の装置の幅 | 26.413 | 0.356 |
| 背中の装置の出（胴の背中の面から） | 13.025 | 0.175 |
| 背中の装置の下端の高さ（足の底から） | 26.766 | 0.360 |
| 背中の装置の上端の高さ（足の底から） | 70.106 | 0.944 |
| ヘルメットの幅 | 19.414 | 0.261 |
| ヘルメットの奥行き | 16.117 | 0.217 |
| 胴の奥行き（腰、装置なし） | 9.089 | 0.122 |
| 胸の高さの奥行き（胸の箱〜装置の背面） | 27.601 | 0.372 |

- 背中の装置の幅は体の幅とほぼ同じ（比 1.00）。出は胴の奥行きの 1.43 倍。上端はヘルメットの上端のすぐ下（身長の 94%）、下端は腰の下（36%）。
- 装置は「大きな箱＋その下の小さな箱」の2段。胸にも箱が1つ付く。
- クルー（Fable-A、身長 1.20m・2.4頭身）に当てはめると、頭が大きい分そのままの比は使えない。使えるのは「幅は胴と同じ、出は胴の奥行きの 1〜1.4 倍、上端はヘルメットの中ほど、下端は腰」という関係。身長比をそのまま掛けた場合の参考値は 高さ 0.70m・幅 0.43m・出 0.21m（1.20m のクルーには大きすぎる）。

## 5. 第1段で使う寸法の案（`Ship_Stack`）

実寸（1 unit = 1m）。大きさは 4章の公表値、形と配置は 1〜2章のモデルから。「推測」の値は見た目の釣り合いで決めた仮の値で、スクリプトの定数にして後から直せるようにする。

**並べ方（案）**：長軸を Z にして、ノズルの出口を下（z=0）、その上に機械船、司令船、月着陸船の順（アポロ13号の、月着陸船を司令船の先端につないだ配置）。月着陸船は上下を逆にして上段の天面を司令船の先端に向ける。ルートの原点はノズルの出口の中心。長軸を別の向きにするなら親が決める（未決定）。

| 部品 | 寸法（m） | 根拠 |
|---|---|---|
| `Ship_SM` ノズル | 口径 2.5、機械船の外に出る長さ 2.8、のどの直径 0.65 | 公表値（中・推測）。のどはモデルの比（口径の 0.26） |
| `Ship_SM` 円筒 | 直径 3.9、長さ 4.7 | 直径は公表値。長さは 全長 7.5 − ノズル 2.8 |

| `Ship_CM` | 底面の直径 3.9、高さ 3.2 の円錐（先端は直径 0.8 で切る）＋先端にドッキング部の短い円筒（直径 0.8、長さ 0.3） | 公表値。合計 3.5 にして全長 11.0 に合わせる |

**三角数の見積もり**（上限 6,000）：ノズル 16分割×4段 ≈ 130／機械船の円筒 24分割 ≈ 150／外板 ≈ 60／小型噴射器 4か所×約 100 ≈ 400／司令船 24分割 ≈ 150／月着陸船の下段 ≈ 150、上段 ≈ 400、脚 4本×約 250 ≈ 1,000、ノズル ≈ 100。合計 約 2,500。残りはベベルとアンテナ1つに回せる。

**付けない物**：旗・文字・記章（計画 D 章）、高利得アンテナの細い骨（太さ 2cm のルールに合わない。付けるなら皿1枚と太い支柱にする）、月着陸船の細いアンテナ類。
