## 1. 一言で・2本の柱

- 一言：アポロ13号のような事故から、最大4人で協力して地球へ帰るゲーム。軌道は NASA GMAT で計算した本物
- 柱1 **科学の裏付け**：帰り道の2本（A・B）を NASA GMAT で計算し、その線をそのまま画面に描く。時刻や事故の中身はアポロ13号の NASA の資料に合わせた
- 柱2 **協力して資源をやりくり**：電力・酸素・温度・CO2・燃料が毎秒減る。4つの席が別々の操作を持ち、大事な場面は2人の同時押し
- 動画の文字カードの案（demo-video-ref）：BRING THEM HOME ／ 4 SEATS, ONE SHIP ／ REAL NASA ORBITS (GMAT) ／ EVERY SECOND COSTS OXYGEN

## 2. 遊びの流れと4つの席

- 1プレイ約8〜9分（ルート A 約8分、B 約9分。事故から着水まで6分／7分）。1〜4人。4人なら1人1席、3人なら Comms & Power が Planner も持つ、1人なら全席を切り替える（SPEC 1・6章）
- 流れ：タイトル → 部屋（合言葉）→ ブリーフィング（ヒューストンが説明）→ 設計（予算と重さの中で部品を積み、打ち上げ判定）→ 打ち上げ → 練習（各席が1回ずつ操作）→ かき混ぜスイッチ → 事故（酸素タンク）→ 月の裏（通信が切れる）→ 通信の回復 → 点火 → 再突入 → 着水 → エンディング → 事後レポート（SPEC 2章）
- 事故からの秒：90 で月の裏に入り通信が切れる、210 で回復、240〜280 が点火の窓（40秒）、300（A）／360（B）で再突入、着水は 360／420（SPEC 4章）
- 決まっている物：目的（月の裏を観測して帰る）、事故の中身、マイルストーン12個。自由な物：設計、操作、帰りのルート A／B（点火まで変えられる）（SPEC 1章）
- 4つの席（席は必ず色＋形）（SPEC 6章）
  - ▲ Pilot：船の向き（Earth／Moon／Burn／Shield など）、軌道の修正、点火
  - ■ Comms & Power：ヒーター・照明・航法・通信のスイッチ、データ送信、点火
  - ● Life Support：酸素タンクのバルブ、CO2 フィルターの交換、タンクのかき混ぜ
  - ◆ Mission Planner：観測機器、帰りのルート A／B を選ぶ。地図・タイムライン・ルートの比較は Planner の画面にだけ出る＝「ほかの人に聞かないと分からない」協力の仕掛け（#157・#200）
- 同時押し：点火（Pilot＋Comms & Power、0.5秒以内）、CO2 フィルターの交換（Life Support＋もう1人）（SPEC 6章）
- 緊張の作り方：酸素漏れは毎秒1%で40秒続く。バルブを閉じるのが1秒遅れるごとに酸素を1%失う。寒さと CO2 で操作が遅くなる（SPEC 6・10章）
- エンディング3つ：ED-A（基準を全部満たして生還）／ED-B（生還したが電力・酸素・温度が基準割れ）／ED-C（電力か酸素が0で途中で終わる）（SPEC 8章）
- 事後レポート：要件4つ（生還・科学・質量・予算）の合否、スコアの内訳、資源の推移。本物のアポロ13号との違いも見せる（SPEC 6・8章）
- 遊んだ例：T1（よい操作・ルート A）は ED-A でスコア 1282。T4（バルブを閉じるだけ）は電力が t=291 で0になり ED-C（SPEC 10章）。動画はこの2つの記録を再生して撮れる（失敗の絵も入れる）

## 3. NASA のデータとツール

### 使い方
- **NASA GMAT R2026a** で帰り道を計算した（自作スクリプト `data/gmat/return_routes.script`。天体の位置は GMAT 付属の DE405）。月の裏を高度 254 km で回る自由帰還軌道に乗り、最接近の2時間後に加速して帰る（data/README.md）
  - ルート A：噴射 0.271 km/s、噴射から再突入まで 63.0 時間（早い・燃料を多く使う）
  - ルート B：噴射 0.052 km/s、70.6 時間（遅い・燃料が少ない）
  - GMAT の時刻をゲームの時刻に対応させた（`data/gmat/time_map.json`。例：事故＝GMAT 52.77 時間、月の裏に入る＝73.99 時間。裏にいる約22分をゲームでは120秒）
  - 画面：地図（押すと全画面）に GMAT の線をそのまま描く。窓の外の地球が月の裏の間は月に隠れるのも GMAT の時刻と一致
- **アポロ13号の事実**（docs/reference/apollo13-data.md）：打ち上げ 1970-04-11、事故は酸素タンク2（打ち上げから 55:54:53）、燃料電池が酸素を失って電気も止まった、月の裏で通信が切れた、事故の後は自由帰還軌道に戻して帰った
- **本物の交信の声**：事故の瞬間に、アポロ13号の「Houston, we've had a problem」の交信（NASA、Wikimedia Commons 経由）を切り出して流す
- **NASA の画像**：地球（Blue Marble: Next Generation）、月（NASA SVS 4720 CGI Moon Kit）

## 4. 見た目と遊びやすさ：決めたことと理由

- **あつまれ どうぶつの森の方向**：波打つ吹き出し、名前タグ、指さしの手、豆形の選択肢、数のチップ。本人に「AI っぽい」と言われ、参考画像12枚（docs/reference/art-ref/acnh/）を基準に全画面を作り替えた（#190）。ゲームには任天堂の素材を入れていない
- **明るい面と暗い面の組み合わせ**：船内の計器（ゲージ・地図・タイムライン）だけ濃紺、声・操作・警告・タイトル・設計・レポートは明るい。暗い中で「読む物・押す物」だけ明るいので、見る所が分かる（#146）
- **一人称の計器盤**（Taiga、#167・#205）：数値は船内の3Dの計器の針で読む。宇宙船の中にいる感じを出すため。V キーで今までの見下ろしに戻る
- **less is more（引き算）**（#210・#212・#216。Fable の相談の Plan B）：同じ言葉が何か所にも出ていた（「Burn now」4か所、「Practice」4か所、「NASA GMAT」3か所）のを1か所にした。3D の盤を主役にし、押した結果は針・ランプ・揺れで返す
  - 置き場所の決まり：いま何をするか＝上のまん中の1行／残り時間＝右上のチップ1つ／ヒューストン＝低い吹き出し（2行まで、盤を隠さない）／状態＝3D の盤／地図＝右上の小さいボタン、押すと地図だけが全画面
  - 月の裏で通信が無い間は吹き出しを出さず、盤のヒューストンの画面に赤い「電波なし」の印を出す
  - 案 A（スワイプで見回して3Dのレバーで選ぶ）は作らなかった：4席ぶんの作り直しが数時間では終わらない、スマホで押せる大きさが取れない、見回している間に警報を逃す
- **god is in the details（手触り）**（#216）：針が少し行き過ぎて戻る・危ない帯で震える、席を替えるとカメラが少し行き過ぎて止まる、地図を開くと船の印が脈打つ、練習が1つ済むとチェックがぽんと付く
- **ヒューストン＝先生**：宇宙を知らない高校生にも分かるように、ヒューストン（地球から無線で導く管制チーム）が説明する。ブリーフィングで「ヒューストンとは誰か」「船は操縦できない」「月の裏で無線が切れる」を言う。事故の中身は言わず驚きを残す（#152）
- **誰でも遊べる決まり**（ui-guidelines.md）：状態は色＋アイコン、席は色＋形（▲■●◆）で色だけに頼らない／押せる範囲は 96 以上／文字は 22 以上／1つの部品に文は1行
- 画面の文字は英語。ヒューストンの台詞は CEFR A2〜B1、1本80字以内、専門用語は言い換え（story/briefing.md）
- 打ち上げの字幕は「INSPIRED BY APOLLO 13 (1970)」。本物の再現とは言わない

## 9. 言ってはいけないこと・限界

- 軌道の物理を毎秒計算しているわけではない。GMAT の出力（CSV）を描き、ゲームの時刻に対応させている。資源はサーバーの簡単なモデル（秒刻み）
- 「アポロ13号の再現」ではなく「INSPIRED BY」。ゲームではバルブを閉じれば漏れが止まるが、本物は止まらなかった。本物の乗員は3人＋地上の管制（ゲームは席4つ）
- 本物の4人での通しは、記録が無い（サーバーと UI は4人に対応）
- まだ確かめていない：手触りの動き（止まった絵でしか見ていない）、BGM の音、かき混ぜの場面と 844×390 のエンディングの見た目
- docs との食い違い（docs/design が正。直すなら Issue）：`storyboard.md` と `art-direction.md` はカメラが「見下ろし 50°」のままで、一人称（#205）のことが書かれていない。一人称では自分のクルーの表情が映らないので、動画では見下ろしの絵を数秒はさむとよい
- GMAT のメーター（地球まで・月まで・速さ）は本人の指示で今は出していない（#212）。ピッチで NASA のデータを見せたいなら、地図の中か動画の文字で見せる
