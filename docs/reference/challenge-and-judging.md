## 1. お題：Space Mission Design Game

- 難しさ：Intermediate、Beginner/Youth。分野：Games
- 一言：ミッションを**設計から運用まで**体験でき、技術の判断・限られた資源のやりくり・選んだことが成否にどう響くかを確かめられるゲームを作る

### 背景
- ミッションは、目的・宇宙船・観測機器・ロケット・軌道・電力・重さ・通信・予算・寿命が絡み合う。1つを良くすると別の所が苦しくなる（例：よい観測機器 → 科学の価値は上がるが、重さ・電力・データ量・費用も増える）
- 学生がミッション全体を試せる場がない。今のツールは軌道だけ、ロケットだけなど単体が多い
- ゲームなら、試す → 制約にぶつかる → 成功からも失敗からも学べる。1人でも最大4人のチームでも

### Objectives（求められていること）
1. ミッションの設計と運用の流れ全体を体験できるゲーム。1人でも、最大4人の協力でもよい
2. できるとよいこと：目的を決める／要件を決める／宇宙船を設計する／観測機器を選ぶ／ロケットと軌道を選ぶ／予算・重さ・電力・通信・データ・寿命をやりくりする
3. 1つの判断がミッションのほかの部分にどう響くかが見える
4. 強い解決策の例：動くゲームかシミュレーション＋分かりやすい UI、ミッションを組み立てる仕組み、資源のやりくり、最大4人の協力、シミュレーションと評価
5. ほめる対象：よい技術判断・資源の効率・うまい協力・目的の達成
6. 独創的な遊び方・見せ方・スコア・シナリオで、楽しさと「悩む・トレードオフ・協力」を両立する

### Potential Considerations（必須ではない）
- 遊び：予備知識なしで遊べる／1人とチーム両方／役割分担（計画・設計・科学・通信・資源）／成功・失敗の**理由**が分かる／何度も試せる／スコア／難しさやシナリオ
- 設計：まず目的を決める／大きな判断には代償を付ける／正解は1つではない／現実に近い制約
- 宇宙船と機器：構造・電源・バッテリー・通信・計算機・姿勢制御・観測機器。機器ごとに重さ・電力・費用・データ・科学の価値が違う
- 軌道と打ち上げ：軌道の選択肢と特徴／ロケットごとの運べる重さと費用／重さと軌道がロケットに合うかの確認
- 資源：重さ・電力・予算・データ・通信・時間をはっきり画面に出す
- 協力：役割は分けて、決めるのは全員で／優先順位がぶつかって話し合う場面／結果が連携で決まる
- 教育：やさしい言葉で、ゲームの中で教える／正しいか間違いかだけでなく**なぜか**を教える
- 足すとよいもの：思いがけない出来事、資源が減っていくダッシュボード、終わったあとのレポートと事後の分析、ランキング、設計の保存と比較 など

### 私たちのゲームとの対応
| お題 | 私たちのゲーム（SPEC） |
|---|---|
| 設計（予算・重さ・部品） | 設計画面で予算と重さの中で部品を積み、打ち上げ判定 |
| 軌道の選択 | 帰り道 A／B（NASA GMAT で計算）を Planner が選ぶ |
| 資源のやりくり | 電力・酸素・温度・CO2・燃料が毎秒減る |
| 最大4人・役割 | 4つの席（▲■●◆）、2人の同時押し |
| 話し合い・連携 | 地図とルートの比較は Planner にしか見えない |
| 思いがけない出来事 | 酸素タンクの事故 |
| 評価・事後の分析 | エンディング3つ、事後レポート（要件4つの合否・スコア・資源の推移） |
| やさしい説明 | ヒューストンが先生として説明する |

- お題とのずれ：「目的を決める」「ロケットを選ぶ」は私たちのゲームに無い（目的は決まっている。SPEC 1章）。どちらも could なので必須ではない。聞かれたら「事故から帰ることに絞った」と答える
- `planning-meeting.md` の「審査で重視される『危機管理におけるトレードオフ』」は公式の文に無い。お題が言うのは「ミッション設計のトレードオフ」

## 2. 審査基準（どの段階でも、5つを各1〜5点）

| 基準 | 見られること | 私たちが言えること |
|---|---|---|
| Impact | 問題の大きさ、どれだけ多くの人を助け・刺激するか | 宇宙を知らない高校生でもトレードオフを体で覚えられる |
| Creativity | 新しさ、今あるものを意味のある形で良くしたか | アポロ13号のような事故 × 4席の協力、同時押し、Planner にしか見えない地図 |
| Validity | 科学に沿っているか、動くか、使いやすいか | GMAT の軌道、NASA の資料に合わせた時刻、遊べる完成品、誰でも遊べる UI の決まり |
| Relevance | お題に真正面から答えているか。**NASA のデータが中心で、飾りでない**か | 帰り道の線は GMAT の出力そのもの、本物の交信の声、NASA の地球と月 |
| Presentation | お題・解決策・意義が伝わるか、物語として引き込むか。デモとプロジェクト全体の両方で採点 | ガイドに「最初の4つと同じくらい力を入れて」とわざわざ書いてある |

## 3. 賞（最後の審査で選ぶ10個）

- Best Use of Science：科学の方法をいちばん正しく使った
- Best Use of Data：宇宙のデータを身近にした・独自に使った
- Best Use of Technology：技術の使い方がいちばん新しい
- Galactic Impact：地球や宇宙の暮らしをいちばん良くしそう
- Best Mission Concept：構想と設計がいちばん現実的
- Most Inspirational：いちばん心を動かす
- **Best Storytelling Award**：オープンデータの可能性を物語でいちばん独創的に伝えた
- Global Connection Award：技術で世界の人をいちばんつないだ
- **Art & Technology Award**：技術と表現をいちばんうまく組み合わせた
- Local Impact Award：地元をいちばん変えそう

太字の2つが私たちに一番合う（物語と見た目、GMAT の線を描いている）。
